Мониторинг  

- Prometheus - стандарт для микросервисных и облачных сред(kubernetes), работает периодически опрашивая цели по hhtp, собирая метрики. Данные хранятся в виде временных рядов и индексируются по меткам(очень гибкая фильтрация). Для запросов используется собственный язык PromQL.
- Zabbix - Классическая система мониторинга все в одном, подходит для классических серверов и сетей, собирает данные по snmp и jmx, так же поддерживает агентов для сбора данных.
- Grafana - Универсальный инструмент визуализации, его задача подключаться к источникам данных и строить на их основе информативные дашборды.

- Zabbix в докер на убунту(три контейнера - по одному на процесс)
  - Заббикс состоит из нескольких частей:
    - заббикс сервер - принимает данные от агентов, обрабатывает триггеры, шлет алерты
    - база данных - в моем случае PostgreSQL, хранит конфигурацию, историю метрик, события
    - вэб интерфейс - графики, дашборды, настройка хостов и тд
    - заббикс агент - легковесная программа, которая "живет" на выбранной машине и собирает метрики   
  - mkdir ~/zabbix-docker && cd ~/zabbix-docker - для начала создадим директорию и docker-compose.yml в ней [Докер компоус для заббикса](Zabbix.yml)
  - cd ~/zabbix-docker - перейти в каталог с докер компоус файлом
  - sudo docker compose up -d - запустить компоус файл (up -d создаст контейнеры, поднимет сеть, volumes - все это в фоне)
  - sudo docker ps -a - проверим наши контейнеры
  - в браузере http://10.42.98.113:8081 - входим в веб морду (Admin\zabbix - дефолтные логии пароль, позже их разумеется нужно сменить)
  - sudo apt install -y zabbix-agent - установка агента
  - sudo nano /etc/zabbix/zabbix_agentd.conf - конфигурационный файл заббикс агента, там нас интересуют следующие строки:
    - Server=10.42.98.113,172.19.0.0/16 - адрес хоста на котором все крутиться и адреса сети докер контейнера
    - ListenPort=10050 - какой порт слушать
    - ListenIP=0.0.0.0 -  какой интерфейс(0.0.0.0 на всех)
    - ServerActive=10.42.98.113:10051 - куда будет стучаться сам агент
    - Hostname=ubuntuvm - имя хоста(ОБЯЗАТЕЛЬНО должно совпадать с именем в веб интефейсе)
