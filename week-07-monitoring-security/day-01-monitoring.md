Мониторинг  

- Prometheus - стандарт для микросервисных и облачных сред(kubernetes), работает периодически опрашивая цели по hhtp, собирая метрики. Данные хранятся в виде временных рядов и индексируются по меткам(очень гибкая фильтрация). Для запросов используется собственный язык PromQL.
- Zabbix - Классическая система мониторинга все в одном, подходит для классических серверов и сетей, собирает данные по snmp и jmx, так же поддерживает агентов для сбора данных.
- Grafana - Универсальный инструмент визуализации, его задача подключаться к источникам данных и строить на их основе информативные дашборды.
