Анализ места на диске  

- df - свободное место в файловой системе(в целом)  
  - df -h - базовое использование
  - df -hT - с типом файловой системы
  - df -h --total - с итогом
  - df -i - показывает айноды(если место занято айнодами, а базовый вызов показывает что место еще есть, значит создано много мелких файлов)
- du - считает размер каталогов и файлов   
  - du -sh /var/log - базовое использование
  - du -h --max-depth=1 /var - размер каждого подкаталога первого уровня
  - du -h --max-depth=1 /var | sort -hr | head -10 - 10 самых больших каталогов в var
- ncdu - интерактивный аналог du
  - sudo apt install ncdu - установка
  - sudo ncdu / - полное сканирование
  - ncdu /home/kicha   
- find - вообще это универсальный инструмент поиска файлов и один из самых частых сценариев это поиск файла по размеру
