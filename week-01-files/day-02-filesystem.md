С файловой системой Linux я уже знаком, но думаю, повторить не помешает.

- /etc - раздел с конфигурационными файлами системы (/etc/apt/sources.list, /etc/sudoers, /etc/hostname, /etc/hosts)
- /var - раздел для различных логов, кеша и подобных данных
- /home - директория с профилями пользователей
- /opt - раздел с программами установленными отдельно.
- /tmp - временные файлы

Наиболее часто используемые команды для работы с файловой системой:
- ls - список файлов и папок в директории(ls -a, ls -la)
- cd - для перехода в другую директорию
- pwd - полный путь текущей директории
- cat - вывод содержимого файла
- less - построчный просмотр файла
- head - первые строки файла
- tail - последние строки файла
- cp - копировать файл/каталог
- mv - переместить файл/каталог (если файлы в одной директории, то это переименование)
- rm - удаление файлов и каталогов (rm -r удалить каталоги и все содержимое рекурсивно)
- ln - создать ссылку на файл или каталог
