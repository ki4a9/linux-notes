Права доступа к файлам\папкам.

 - /chmod - задает права доступа к файлам и каталогам.
   -  три категории пользователей (user, group, others) + три типа прав (read, write(изменение\удаление), execute(выполнение))
   -   два способа задать права:
       - числовой: r=4,w=2,x=1 (для каждой категории мы их складываем) 

         например: chmod 644 файл > владелец(rw-) 4+2, группа и остальные(r--) 4

       - символьный: chmod [кто][действие][права] файл (кто-u,g,o,a(all); действие(добавить(+), убрать(-), присвоить(=)); права(r,w,x))

         например: chmod u+x файл - добавить владельцу право на выполнение, chmod go-w файл - запретить группе и остальным запись файла


- /chown - смена владельца файла\каталога или группы владельцев файла\каталога.
  - sudo chown [пользователь]:[группа] путь  (всегда от суперпользователя)
    
     например:
    - sudo chown kicha файл.txt сменить владельца
    - sudo chown kicha:developers папка/ сменить владельца и группу
    - sudo chown :developers папка/ сменить только группу
