Текстовые утилиты.

- /grep - ищет строки, слова по шаблону(регулярным выражениям) в текстовых файлах или выводах других команд.
   - grep 'опции' шаблон 'файл'. например: grep "error" /var/log/syslog.

   еще несколько полезных примеров:
  - grep -i "error" - игнорировать регистр
  - grep -v "шаблон" - инвертировать поиск(все кроме шаблона)
  - grep -c "error" app.log - посчитать количество совпадений
  - grep -r "error" - рекурсивный поиск по папкам и подпапкам

  это малая часть того что может grep, я сознательно не стал приводить в пример работу с регулярными выражениями, думаю, что это тема отдельного дня.  

- /cut - извлекает части строк из тестовых данных
  - cut 'опции' 'файл'. рассмотрю режим работы "по полям", так как он самый часто применяемый. 
    - например: cut -d ':' -f 1 /etc/passwd (вывести имена имена пользователей из файла(показать только первое поле, разделитель - :))
    - cut -d ':' -f 1,3,7 /etc/passwd - показать 1, 3 и 7 поля
  - так же существует "по байтовый" режим работы, для тех файлов где один символ занимает один байт.
    - echo "abcdef" | cut -b 1,4       # a, d 
  - и "по символьный" режим
    - echo "привет" | cut -c 1-2       # пр
      
рассматривать подробно каждый режим не вижу пока особого смысла.  

- /sort - сортирует строки в текстовых файлах и текстовых данных.
  - sort 'опции' 'файл'. ниже  пара примеров
    - sort -n numbers.txt - числовая сортировка
    - sort -r file.txt - обратный порядок(по убыванию)
    - sort -t: -k3n /etc/passwd - сортировка по конкретному полю
     
- /uniq - утилита для работы с повторяющимися строками: умеет удалять дубликаты, показывать повторы, считать сколько раз встречается каждая строка. uniq считает только СОСЕДНИЕ строки, поэтому перед использованием uniq делают sort.
  - uniq (опции) (входной файл(выходной файл)). типовой конвейер выглядит вот так - sort file.txt | uniq. далее пара примеров:
    - sort file.txt | uniq -c перед каждой строкой выводить количество повторений. 
    - sort file.txt | uniq -d вывести строки, которые встречаются более 1 раза.
    - sort file.txt | uniq -D вывести все повторяющиеся строки.
    - sort file.txt | uniq -u вывести строки, которые встречаются ровно 1 раз.

- /wc - утилита для подсчета строк, символов, слов и байтов в текстовых файлах и текстовых данных.
   - wc (опции) (файл)
     -  wc /etc/passwd - вывод будет   37   152  2890 /etc/passwd (37 строк, 152 слова 2890 байт)
   - наиболее частый вариант использования опция -l (выводит количество строк)
     - wc -l /etc/passwd

- /awk - это мини язык программирования для обработки текста(условия, циклы, переменные, массивы). Он читает вход по строкам, разбивает каждую строку на поля и выполняет над ними заданные правила. не хочу особо углубляться и изучать все эти несметные способы использования awk, поэтому напишу только основное.  
  - awk (программа) файл. например: awk '{ print }' file.txt - выполнить print для каждой строки файла
  - "программа" как правило имеет синтаксис типа:
      - шаблон { действие } - awk '$3 >= 100 { print $1, $3 }' data.txt - шаблон это условие, если оно истинно выполняется действие

  awk автоматически разбивает строку на поля по пробелам:
  - $0 — вся строка: alice 25 100
  - $1 — первое поле: alice
  - $2 — второе поле: 25
  - $3 — третье поле: 100
  - $NF — последнее поле: 100
  - NF — количество полей в строке: 3
  - NR — номер текущей строки: 1, 2, 3,
