Пакеты, пакетный менеджер.

- /apt update - эта команда обновляет локальный индекс пакетов, проще говоря она "проверяет" репозиторий на появление в них новых пакетов.

- /apt install - команда для установки пакетов, она сама находит пакеты в репозиториях, разрешает зависимости, скачивает и устанавливает deb файлы. ниже базовый синтаксис.
  -  sudo apt install <пакет>
  -  sudo apt install <пакет1> <пакет2>
  -  sudo apt install <пакет>=<версия>
  -  sudo apt install ./локальный_файл.deb
 
  полезные опции для apt install:
  
  - -y - автоматически отвечать "да", на все вопросы.
  - --no-install-recommends - не ставить рекомендованные пакеты.
  - --reinstall - переустановить пакет.
  - -s - показать, что будет сделано, без реальной установки.
  - -f - исправление сломанных зависимостей.
  - --no-upgrade - не обновлять, если пакет уже установлен.
  - --only-upgrade - только обновить, если пакет уже установлен. новый не ставить.
