Межсетевой экран  

Существуют два основных инструмента(iptables и nftables), а так же ufw для более наглядного управления ими.  

фаерволл в линукс работает на 3 ключевых понятиях:  
- Таблицы - Разделы для разных типов обработки: filter(фильтрация пакетов), nat(для маршрутизации\подмены адресов)
- Цепочки - INPUT(входящие пакеты), OUTPUT(исходящие пакеты), FORWARD(пакеты, проходящие через устройство транзитом)
- Правила - Конкретные инструкции(пакет пришел на порт 22 - пропустить(ACCEPT), если на 23 -выбросить(DROP))

- iptables - классический инструмент:
  - sudo iptables -L -n -v --line-numbers - посмотреть текущие правила(n- не преобразовывать ip в имена, v- подробно, с номерами строк)
  - sudo iptables -A INPUT -p tcp --dport 22 -j ACCEPT - разрешить входящий SSH(-p tcp - протокол, --dport 22 - порт, -j ACCEPT - действие)
  - sudo iptables -P INPUT DROP - запретить все входящие запросы, кроме разрешенных
  - sudo iptables -D INPUT 1 - удалить правило по его номеру
 
  Действия могут быть трех видов - ACCEPT, DROP, REJECT(отклонить)
  Главный минус iptables в том, что правила не сохраняются после перезагрузки (для этого нужно использовать отдельные инструменты)


- nftables - современный инструмент:
  - sudo nft list ruleset - увидеть список правил
  - sudo nft add table inet my_filter - создать таблицу(пустую)
  - sudo nft add chain inet my_filter input '{ type filter hook input priority 0; policy drop; }' - создать цепочку в таблице
  - sudo nft add rule inet my_filter input tcp dport 22 accept - добавить тиуда правило
 
в nftables правила применяются все сразу и есть встроенное сохранение конфигурации  


- ufw - это "обертка" для настройки iptables\nftables:
  - sudo ufw status - ну тут понятно, статус посмотрим
  - sudo ufw enable - включим фаервол
  - sudo ufw allow 22/tcp - разрешим порт 22
  - sudo ufw allow from 192.168.1.50 - разрешить доступ с конкретного ip
  - sudo ufw delete allow 80/tcp - удалить правило  
 
в ufw правила применяются мгновенно и сохраняются после перезагрузки
