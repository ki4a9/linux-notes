DNS  

- /etc/hosts - файл в котором записаны сопоставления днс и ip адресов сайтов. система проверяет его содержимое раньше чем указанные DNS.

- /etc/resolv.conf - файл, где указанны адреса DNS серверов. указать можно максимум 3, остальные будут игнорироваться. обязательно нужно выяснить переписывается ли файл системой. нужно проверить куда ведет файл и посмотреть: ls -l /etc/resolv.conf. если там что то необычное то скорее всего задавать dns нужно через netplan.

dig - основной инструмент для отладки dns.   
важное в выводе команды:  
- status: NOERROR(запрос успешен), NXDOMAIN(имя не существует), SERVFAIL(ошибка сервера), REFUSED(отказано)
- SERVER - какой днс сервер ответил

чаще всего пользуюсь:  
- dig @8.8.8.8 google.com - спросить о днс имени у конкретного днс сервера
- dig +trace google.com - трассировка днс запроса

nslookup - более простой инструмент для отладки dns.   
- nslookup google.com 8.8.8.8 -  спросить о днс имени у конкретного днс сервера

И dig и nslookup обходят(не читают) файл hosts - они спрашивают днс напрямую. Это важно помнить, когда ping работает, а dig(nslookup) нет.
