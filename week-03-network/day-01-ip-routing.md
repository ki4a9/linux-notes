IP и маршруты.  

- /ip a - показывает все сетевые интерфейсы и ip адреса, назначенные им.
   - ip link set enp0s3 up - включить интерфейс
   - ip a add 192.168.1.50/24 dev enp0s3 - добавить ip

 - /ip r - просмотр таблицы маршрутизации.
   - ip r add 10.42.0.0/24 via 192.168.1.254 - добавить статический маршрут
   - ip r show table all - показать все таблицы маршрутизации

- /ss - команда для просмотра сетевых соединений и прослушиваемых портов.
   - ss -tulpn - tcp соединения(t), udp соединения(u), слушающие сокеты и процесс которые используют сокет(lp), числовые порты(n). Чтобы видеть процессы нужны root права.
 
- ping - проверка доступности узла, отправляет ICMP пакеты на указанный хост и ждет ответа.
- traceroute - путь до узла, показывает маршрут по которому пакеты идут до цели.
