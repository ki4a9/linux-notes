SSH  

- SSH - протокол для безопасного удаленного доступа к другой машине. Он шифрует весь трафик(данные и пароли не передаются в открытом виде).
   - Клиент - ssh, scp, sftp, rsync
   - Сервер - sshd(демон который слушает 22 порт)
   - Ключи - для аутентификации без пароля
   - Конфиги - на клиенте(/.ssh/config), на сервере(/etc/ssh/sshd_config)
 
- ssh-keygen - генерация ключей. Пара ключей публичный и приватный. Приватный у тебя, публичный можно раздавать клиентам для подключения(на сервере в файле /.ssh/authorized_keys). При подключении сервер проверит соответствие приватного ключа публичному.
   -  ssh-keygen -t ed25519 -C "kicha@ubuntu" - генерация ключа(-t ed25519 - тип ключа, -C комментарий)
   -  в /.ssh/ появится ряд файлов:
      - id_ed25519 - приватный ключ
      - id_ed25519.pub - публичный ключ
      - known_hosts - список известных хостов(добавляются при первом подключении)
      - authorized_keys - публичные ключи, которым разрешен вход
   
- authorized_keys - файл на сервере /.ssh/authorized_keys, каждая строка - один публичный ключ
   -  ssh-ed25519 AAAAC3NzaC1lZDI1NTE5AAAA... kicha@ubuntu (тип ключа, сам ключ, комментарий)
   -  права доступа должны быть строго определенные(критично) chmod 700 ~/.ssh, chmod 600 ~/.ssh/authorized_keys
   -  ключ можно добавить вручную командой, или просто скопировав содержимое .pub и вставить в authorized_keys на сервере
   -  ключу можно задать ограничения:
      - command="/usr/bin/backup.sh",no-port-forwarding ssh-ed25519 AAAA... backup@host (command= - выполнить только эту команду, no-port-forwarding - запретить проброс портов, from="192.168.1.*" - разрешить подключения только с этой подсети)

- scp - безопасное копирование файлов. копирует файлы между машинами через SSH. Синтаксис похож на cp ,но с указанием хоста.
   -  scp file.txt kicha@192.168.1.20:/home/kicha/ - копировать файл на сервер
   -  scp -r mydir/ kicha@192.168.1.20:/home/kicha/ - копировать каталог на сервер(рекурсивно)
   -  scp kicha@192.168.1.20:/home/kicha/file.txt - копировать файл с сервера
   -  cp -r kicha@192.168.1.20:/home/kicha/logs/ /tmp/ - копировать каталог с сервера(рекурсивно)
   -  scp -P 2222 -i ~/.ssh/id_ed25519 file.txt kicha@192.168.1.20:/tmp/ - копировать файл на сервер с указанием порта и ключа  

 У scp нет докачки при орбрыве. 

 - rsync - инструмент для синхронизации файлов и каталогов. Он передает только изменения, а не все целиком. Отлично подходит для бэкапов. (сильно погружаться пока не буду, все таки этот инструмент не для новичков)   
   - rsync -av /home/kicha/docs/ /backup/docs/ - (rsync (опции) источник назначение) - локальная синхронизация
   - rsync -av /home/kicha/docs/ kicha@192.168.1.20:/backup/docs/ - удаленная синхронизация
   - про слэш в конце - (/home/kicha/docs/ — копирует содержимое каталога), а без слэша в конце копируется сам каталог внутри назначения.
