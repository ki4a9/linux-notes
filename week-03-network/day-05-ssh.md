SSH  

- SSH - протокол для безопасного удаленного доступа к другой машине. Он шифрует весь трафик(данные и пароли не передаются в открытом виде).
   - Клиент - ssh, scp, sftp, rsync
   - Сервер - sshd(демон который слушает 22 порт)
   - Ключи - для аутентификации без пароля
   - Конфиги - на клиенте(/.ssh/config), на сервере(/etc/ssh/sshd_config)
 
- ssh-keygen - генерация ключей. Пара ключей публичный и приватный. Приватный у тебя, публичный можно раздавать клиентам для подключения(на сервере в файле /.ssh/authorized_keys). При подключении сервер проверит соответствие приватного ключа публичному.
