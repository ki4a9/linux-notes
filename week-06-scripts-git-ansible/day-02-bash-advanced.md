bash продвинутый  

- Аргументы - во время запуска скрипта аргументы внутри доступны через специальные переменные ./script.sh arg1 arg2
  - $0 - имя скрипта
  - $1, $2, - аргументы по номерам
  - $# - количество переданных аргументов(число)
  - $@ - все аргументы как отдельные слова
  - $* - все аргументы одной строкой

- set -euo pipefail - защита от ошибок(если что то пойдет не так скрипт завершиться)
  - set -e - скрипт завершается, если любая команда вернет ненулевой код(ошибку)
  - set -u - скрипт завершиться, если попытается использовать необъявленную переменную
  - set -o pipefail - если любая команда в пайпе упала, весь пайп считается упавшим
