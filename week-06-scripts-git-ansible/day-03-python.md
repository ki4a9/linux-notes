Python  

- os - модуль для работы с операционной системой, позволяет взаимодействовать с файловой системой и окружением
  - os.path - работа с путями
  - os.environ - доступ к переменным окружения
  - os.makedirs() - создание вложенных директорий
  - os.listdir() - список файлов в папке

- with open - работа с файлами, она автоматически закрывает файл, даже если внутри произошла ошибка
  - 'r' - чтение
  - 'w' - запись(перезаписывает файл)
  - 'a' - дозапись(дописывает в конец)
