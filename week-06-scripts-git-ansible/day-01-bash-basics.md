bash основы  

- bash-скрипт - это текстовый файл с командами, которые выполняются последовательно. для запуска нужно сделать файл исполняемым(chmod +x) и указать интерпретатор в первой строке скрипта(#!/bin/bash)
- Переменная - именованная ячейка для хранения данных

  - Специальные переменные
    - $0 - имя скрипта
    - $1, $2,.. - аргументы скрипта
    - $# - количество аргументов
    - $@ - все аргументы
    - $? - код возврата последней команды(успех=0)
    - $$ - PID текущего процесса
    - $USER, $HOME, $PATH - имя пользователя, домашний каталог, пусть исполняемых файлов
- Условия -
   - if/elif/else (критично важно следить за пробелами внутри скобок)

   - Операторы сравнения для чисел
     - -eq - равно
     - -ne - не равно
     - -gt - больше
     - -ge - больше или равно
     - -lt - меньше
     - -le - меньше или равно
   - Операторы сравнения для строк
     - = или == - равно
     - != - не равно
     - -z - строка пустая
     - -n - строка не пустая
   - Операторы сравнения для файлов
     - -e - существует
     - -f - обычный файл
     - -d - каталог
     - -r - доступен для чтения
     - -w - доступен для записи
     - -x - исполняемый
