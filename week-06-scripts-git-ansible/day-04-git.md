Git  

- Git - система контроля версий(сохранение снапшотов, откат к старым версиям, параллельная работа над проектом)
  - Репозиторий - папка проекта, за изменениями которой следит git
  - Коммит - снимок текущего состояния файлов(сохранение), каждый коммит система помнит
  - Ветка(branch) - параллельная копия проекта, ее можно использовать для тестов, а потом влить(merge) в главную ветку
  - init - инициализация репозитория (git init)
  - commit - сделать коммит (git commit -m "Добавил скрипт бэкапа")
  - push - отправить код на сервер(на github)
  - pull - скачать изменения с сервера
