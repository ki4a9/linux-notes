Ansible  

- Ansible - инструмент для автоматизации, позволяющий управлять множеством серверов с одного компьютера, не устанавливая на них дополнительного ПО. Описываешь желательное состояние системы(playbook), и ансибл приводит серверы к этому состоянию
  - inventory - файл со списком серверов, сгруппированных по ролям, в нем указываются данные для подключения(IP, user names, ssh keys)
  - playbook - сценарий автоматизации написанный на языке YAML, там ты описываешь, что и в каком порядке нужно сделать на группе серверов, чтобы привести их к нужному состоянию
  - modules -  из этих модулей строятся задачи в плейбуках, каждый модуль выполняет конкретную операцию(установить пакет, скопировать фал и тд)

 Одна из особенностей ansible - можно запускать плейбук несколько раз, он не будет вносить изменения если система уже находится в описанном состоянии

- Установка и настройка управляющего узла ансибл
  - sudo apt install ansible
  - ssh-keygen -t ed25519 - генерация ssh ключа (если на все вопросы ответить enter, файлы ключа появятся в ~/.ssh/(id_ed25519 (приватный) и id_ed25519.pub (публичный)))
  - ssh-copy-id kicha@10.10.10.3 - отправка публичного ключа на управляемый узел(на каждом управляемом узле должен быть такой же пользователь как и на управляющем)
  - mkdir ~/ansible && cd ~/ansible - в домашней директории создаем папку ансибл и переходим туда
  - nano hosts - создаем файл хост, где будут указанны управляемые сервера и их переменные
