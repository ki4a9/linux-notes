systemd  
systemd - управляет службами, устройствами, точками монтирования, сокетами и таймерами через юниты. основные инструменты - systemctl для управления и journalctl для логов.  

systemd управляет юнитами. юнит(unit) - это объект, ресурс системы, который systemd запускает, останавливает и отслеживает.  
типов юнитов существует не мало, пока что я буду работать с .service(служба(демон) или группа процессов) и .mount(точка монтирования файловой системы). возможно еще .target(группа юнитов)    


systemctl - основная команда для управления systemd.    
  - systemctl start nginx - запуск службы nginx.  

другие виды команд: stop, restart, reload(перечитать конфиг без запуска), enable, disable, mask(запрет запуска), status  

journalctl - просмотр логов systemd.  
  - journalctl -u nginx  

таргеты - набор юнитов, которые systemd запускает вместе, чтобы привести систему в определенное состояние. что то типа состояния системы
