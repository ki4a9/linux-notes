Cron и systemd timers  

Cron - это самый распространенный способ запускать задачи по расписанию в linux. демон cron(crond) проверяет и выполняет задачи из файлов crontab.  
- crontab -e команда для управления таблицей задач cron(открывает их в текстовом редакторе по умолчанию).
    - синтаксис записей в crontab - пять полей и команда.(1-минуты, 2-часы, 3-дни месяца, 4-месяцы, 5-день недели)
    - 30 8 * * 1-5 /home/user/backup.sh - этот скрипт будет запускаться в 8:30 утра с понедельника по пятницу.
    - вместо полей можно использовать короткие строки синонимы(типа шаблоны настройки): @reboot(выполнить 1 раз при загрузке системы), @daily(каждый день), @hourly(каждый час) и так далее
Systemd timers - современный механизм на смену cron. Вместо одного файла с расписанием используются юниты(unit files) один для расписания(.timer), другой для самой задачи(.service)
