Процессы  
- /ps - это команда, которая показывает снимок процессов на момент их вызова. существует два стиля опций.(в unix есть колонка родительского процесса(PPID), а в bsd несколько колонок, показывающих потребление ресурсов системы процесса(%CPU, %MEM, VSZ,RSS,STAT))

  несколько базовых примеров:    
  ps - процессы текущего пользователя в текущем терминале  
  ps aux - все процессы, BSD-формат  
  ps -ef - все процессы, UNIX-формат  
  ps -e  - все процессы  
  ps -ef | grep ssh - найти процессы ssh
- /top - это динамический монитор процессов в  реальном времени. состоит из сводки(сверху) и списка процессов(снизу).   
 к примеру load average (1\5\15 минут) показывает среднею нагрузку на 1, 5, 15 минут, если эти числа больше количества ядер значит система перегружена.
 в строке %cpu так же важно обратить внимание на показатель wa(ожидание ввода-вывода), если оно высокое, значит диск медленный.  
  top управляется горячими клавишами:
   - M	- сортировать по памяти (%MEM)
   - N	- сортировать по PID
   - u	- показать процессы пользователя
   - k	- убить процесс (запросит PID и сигнал)
   - m  - переключить вид памяти

 - /htop - это интерактивный монитор процессов, тот же top только с псевдографическим интерфейсом. единственный недостаток в сравнении со своими "консольными коллегами" - это отсутствие batch режима (нельзя получить снимок для скрипта)

 - /kill - команда для отправки сигналов процессам. работает по pid(идентификатор процесса). сигналом может быть не только "убийство".  
   пример:   
   kill -сигнал PID  (kill -15 1234)
   самые важные виды сигналов:
   - SIGTERM (15) — правильный способ попросить процесс завершиться. процесс может сохранить данные, закрыть файлы, освободить ресурсы.
   - SIGKILL (9) — крайняя мера. ядро убивает процесс немедленно, без очистки. могут остаться временные файлы, блокировки, сокеты.  
- /nice - запускает процесс с заданным приоритетом, чем ниже значение команды, тым выше приоритет. значение может быть от -20 до +19. обычный пользователь может только понижать приоритет, root может задавать любой.
   nice (опции) команда (аргументы)
   nice -n 19 tar -czf backup.tar.gz /home
   nice -n 19 rsync -av /data /backup
