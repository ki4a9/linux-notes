Пользователи и группы  

Пользователи могу быть 3-х типов (отличаются по диапазону UID) - root(0), пользователи служб, системные пользователи(1-999), обычные пользователи(1000+). Группы делятся по ID точно так же.  
у каждого пользователя есть основная группа(для прав конкретно этого пользователя) и сколько угодно дополнительных(для групповых прав)  

- /etc/passwd - файл со списком всех пользователей.
- /etc/shadow - файл с хешами паролей.
- /etc/group - группы.

- useradd - создает пользователя, но если не указать доп параметры то команда их и не создаст, будет только логин.
- usermod - изменить пользователя. можно блокировать\разблокировать переименовывать, менять группу и добавлять в sudo, даже домашний каталог и оболочку(shell)  можно менять.
- passwd - сменить пароль. помимо этого тоже можно блокировать\разблокировать и даже совсем удалять пароль
