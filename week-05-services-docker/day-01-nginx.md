Nginx  

- nginx - вэб сервер, обратный прокси и балансировщик нагрузки
  - sudo apt install nginx
  - sudo systemctl start nginx
  - sudo systemctl enable nginx
- Виртуальные хосты - server blocks, позволяют на одном сервере(одном ip) размещать несколько сайтов
  - nginx работает от пользователя www-data, его нужно делать владельцем каталога с сайтом
  - sudo nginx -t - проверка синтаксиса файлов перед применением
  - sudo systemctl reload nginx - перечитывает конфигурацию без разрыва соединений
- структура каталогов:
  - /etc/nginx/sites-available/ - все доступные конфигурации сайтов
  - /etc/nginx/sites-enabled/ - символические ссылки на те конфигурации сайтов, что должны быть активны в данный момент
  - /etc/nginx/sites-enabled/default - конфигурация сайта по умолчанию(ее обычно удаляют)
- Обратный прокси - в режиме обратного прокси nginx принимает запрос от клиента, передает его другому приложению, получает ответ и возвращает клиенту(например приложение работает на 127.0.0.1:3000, а мы хотим чтобы пользователи обращадись к нему по адресу http://my-app.com)
